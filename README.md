# shopmate.

**Discover local. Support local. Shop with confidence.**

Shopmate is a frontend prototype of a local-commerce marketplace designed to connect buyers with trusted local sellers and make locally produced goods easier to discover.

The platform aims to give local makers, businesses and independent sellers greater online visibility while providing buyers with a more accessible way to explore products made and sold within their communities.

## Project Vision

Many local sellers have quality products but limited access to the digital marketplace. Shopmate aims to bridge that gap by creating a platform where buyers can discover local products and connect with sellers they can trust.

Our focus is not simply on listing products, but on building a marketplace around visibility, accessibility and trust.

## Current Features

- **Product Discovery:** A product-focused homepage for exploring locally available goods.
- **Category Browsing:** Product categories designed to make discovery easier.
- **Seller Visibility:** Product listings display seller information and verification indicators as part of the intended marketplace experience.
- **Responsive Interface:** A mobile-first layout designed to adapt to different screen sizes.
- **Seller Onboarding Entry Point:** A dedicated section introducing sellers to the platform.

> **Development status:** Shopmate is currently in its frontend development stage. Product information and imagery are demonstration content. Backend integration, real seller verification, authentication, shopping cart functionality and payment processing are not yet implemented.

## Getting Started

To run Shopmate on your local machine:

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/shopmate.git
   ```

2. Navigate into the project directory:

   ```bash
   cd shopmate
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided by Vite in your browser.

### Production Build

To generate an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
